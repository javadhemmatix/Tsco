# TSCO organizational landing page

Persian, RTL, responsive landing page. No runtime packages or build step required. Use Node.js 24 and run `npm start` from `/workspace/Tsco` (port 3000, or set PORT).

The box builder, category filters, product dialogs, color selection, local browser reviews, sample guide download and request-file generation work client-side. Prices and product combinations are illustrative. Product images are CSS illustrations; video and customer logos require approved official assets. Reviews stay in localStorage and are not verified. Forms generate a local request file and do not submit to TSCO. Replace these demonstration paths with approved APIs before production. The guide is an HTML download, not the official catalog.

The optional Google-hosted Vazirmatn font falls back to Tahoma when unavailable. No credentials are required. The linked TSCO website was blocked by the environment proxy, so its content was not verified.
